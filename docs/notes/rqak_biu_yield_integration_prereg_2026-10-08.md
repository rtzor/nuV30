## Contract and limits

Instantiate actual demultiplexed `v30_core`, `v30_rqak_frontend` and `v30_bus_ownership`, with `V30_BUS_OWNERSHIP` and `V30_BIU_YIELD`. Resolve each synchronous line as `~(remote_low | RQAK_DRIVE_LOW)`. Frontend REQUEST goes to the controller and its OR to YIELD_PENDING; YIELD_READY drives CORE_QUIET; genuine BUS_EXCLUDE drives EXCLUDE; inverted CORE_BUS_ENABLE, including its combinational acquisition edge, drives BUS_OWNED. Core CE stays live; do not connect controller CORE_CE or CORE_CE_HALF to core enables. EXTERNAL_GRANT is frontend permission after ACK ends, not INTERNAL_GRANT. Separate external isolation masks all modeled CPU transactions and read input while CPU bus permission is false. RESET independently removes peer drive permission. No SS operations occur during arbitration.

Use actual public instruction bytes and initial register loading. Queue filling in live-progress tests must be natural, without initial queue injection or internal force. Transaction model uses public BS/READY, address announcement, actual T1 lane sampling and write data at completion; registered BIU phase only corroborates. Retain literal checks independent of twin-core agreement. Two macro-ON cores, inactive yield inputs on reference, compare bus, QS and architectural registers for >=200 eligible no-request core clocks per each of the 20 functional profiles. Macro-OFF and other existing gates are separate regressions.

SILICON MATCH remains the only native correctness bar. This chain is synchronous simulation engineering evidence; it does not establish NEC pin timing, physical pad release/ACK alignment, minimum mode, 8080 execution, multiplexed half-clock isolation, production integration or fitted ON timing. Frontend return HIGH-plus-two-CE gap remains engineering policy. No board access or flashing.

## Numeric acceptance bars

Exactly 23 freshly initialized directed profiles:

1. Twelve protected profiles: LOCK even/odd INC, LOCK REP MOVSW with CX=3, and IRQ/two INTA, each crossed with waits 0/1/3. Send a real frontend pulse during genuine exclusion. No internal grant, ACK or external grant until exclusion clears and required protected cycles complete. Check even/odd result 0002 with A5/5A odd neighbors, REP destination 1111/2222/3333 and CX=0, and exactly two INTA, vector/handler/frame literals with terminal HALT IP=0104, CS=0000, SP=07FA, normalized PSW=F202 and frame IP from observed accepted boundary. Observe at least one excluded gap clock between INTA cycles. Hold external ownership for >=32 live core CE intervals, then return through the actual frontend and reach terminal results.
2. One READY/dual-owner/DMA profile using public loop `A1 00 06 A3 02 06 F7 F1 EB F6`, CX=1, DX=0, empty initial queue. Request channel 1 then channel 0 during a real MEMR of 0600 held in READY-low. Retain both requests with both resolved lines HIGH through >=16 actual Tw clocks. No grant or ACK while waiting. Channel 0 must acquire first; channel 1 remains queued. Peer writes 3C5A then 6A35 to 0600 only with matching EXTERNAL_GRANT and CPU bus permission false, never in ACK/internal grant alone. Hold each external owner >=32 live core CE intervals. CPU bus isolation must remain continuous between owners, ACKs and accepted return gaps even though EU may advance. After final return require >=1 fresh completed MEMR at 0600, >=1 completed literal store 6A35 to 0602, AX=6A35 and memory[0602]=6A35. Earlier reads are permitted.
3. One separate natural-prefetch/DIV profile: actual internal acquisition with queue count=6, >=32 live CE intervals while externally owned and >=2 actual EU queue pops during that external ownership. Prove live progression through observed pops, without requiring arbitrary extra execution-state flags. No new BIU cycle/commit/eligible physical preview or modeled CPU completion while isolated. Return must allow execution/transactions to resume. No opcode-specific timing changes.
4. Six started odd-split profiles: read and write crossed with waits 0/1/3. Send the frontend request during the first READ half for the read case and the first WRITE half for the write case, explicitly corroborating phase and kind. Both public completions must occur before INTERNAL_GRANT: one read at each 0201/0202, or two write halves of INC producing 0002 with intact A5/5A sentinels. Grant cannot interpose between partners. Hold external ownership >=32 live CE intervals, return and check literal result. Conservative split policy is not asserted as NEC's native arbitration rule.
5. Three RESET profiles: reset during a nonvacuous READY-low drain with captured pending pulse; reset during ACK drive; reset during established external ownership. After the reset clock REQUEST/GRANT/EXTERNAL_GRANT/RQAK_DRIVE_LOW and protocol errors must be zero, peer drive permission false, controller CPU bus enabled, and no stale external transaction accepted. Deassert reset with idle lines and run >=16 core CE intervals without stale grant/ACK. No HALT terminal or no-request comparison is required for reset profiles.

Every pre-edge and post-edge isolated interval rejects new CPU scheduling/commit, active physical cycle or eligible physical preview and any modeled CPU completion. Check live CE explicitly, including acquisition and release edges. Existing announced commitments and split/excluded work drain before acquisition. Assert one-hot internal and external grants, external grant implies matching internal grant and isolation, drive-low does not overlap external ownership, and resolved ACK echo is not captured as another request. Check continuous bus isolation until final ownership returns; CE low is not a valid isolation assertion in this mode. No unexpected protocol diagnostics in valid profiles.

Watchdogs: reach public workload/request/split target, drain to acquisition after exclusion/READY release, and post-return literal results <=4096 eligible core/controller intervals each; reach actual Tw <=128; return/queued-owner transfer <=128 each. Each directed protocol phase uses these bounds; no hardware latency claim.
