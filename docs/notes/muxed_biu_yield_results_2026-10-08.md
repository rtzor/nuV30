## Mechanism and instrument

`V30_MUXED_YIELD` requires BIU yield, bus ownership and multiplexed AD. The core uses the same low/high permission terms for actual AD assignments and published AD_OE. Raw BIU operands/OEs, last_ad latches, turnaround flop, scheduling, EU, saved state and tables are unchanged. The replacement controller factors existing quiet/nonexcluded/pending eligibility out of CE for opt-in bus permission only. Registered GRANT acquisition remains on actual CE. Default permission retains the old CE qualification. No new state or opcode case is introduced.

Core CE/HALF remain live; controller and frontend use actual core CE. The public transaction instrument captures the actual AD high-address one-shot at announcement, then low address/UBE before the first T1 HALF. A late T1 can already carry status in the high lane. It drives read/INTA data on the shared low pins and samples writes from actual AD at completion. ADDR_O/DATA_O corroborate the instrument. A read-only pin-history shadow accumulates actual CPU-driven lanes at core CE and independently checks acquisition retention. Peer DMA writes are permission-gated memory bookkeeping, independently of the CPU actual-AD transaction oracle; they are not decoded native DMA transactions. Peer-drive patterns separately exercise resolved pins. Explicit permissions/OEs and distinct resolved peer patterns address Verilator's two-state tri-state limitations; undriven values are not physical Z evidence.

The six non-clocked BUS_OWNED interventions are separate combinational pad tests: real write-T1 address and data around an unmasked HALF, and read-T2 high-status drive, each at divisors2/3/4. The peer pattern `559C1` has zeros exposing residual drive in the exercised lanes; high-status coverage explicitly checks an absent peer bit. Internal operands/raw OEs/latches must stay unchanged, published OE must become zero, resolved AD must equal the peer and original CPU drive must return before further clocking. These interventions are not valid clocked arbitration.
